## Features

- **Data Collection**: Automatically fetch equity data from JSE through a Yahoo Finance API.
- **Performance Analysis**: Calculate key metrics (e.g., ROI, volatility, moving averages).
- **Visualization**: Generate interactive charts for trends and comparisons.
- **Portfolio Optimization**: Simulate portfolio strategies and risk assessments.
- **Report Generation**: Export insights to PDF/CSV for stakeholder sharing.
